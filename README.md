# 📄 Scribd Document Downloader

Công cụ script Python tự động hóa cào và tải tài liệu Scribd sử dụng Selenium WebDriver và Google Chrome.

## 🚀 Tính năng
- Tự động khởi tạo trình duyệt Chrome với profile người dùng.
- Tự động cuộn trang, vượt qua lazy load để đọc toàn văn tài liệu Scribd.
- Trích xuất nội dung văn bản và hình ảnh tài liệu.

## 🛠️ Cài đặt & Chạy
```bash
# Cài đặt thư viện
pip install -r requirements.txt

# Chạy script tải tài liệu
python GoogleChrome.py
```
